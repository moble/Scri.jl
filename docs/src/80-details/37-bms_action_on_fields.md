# BMS action on fields

Having worked out how [the tetrad transforms](@ref "BMS action on the
tetrad"), we can read off how the field components built from it
transform.  Every asymptotic component is a contraction of a curvature
spinor (or tensor) with some number of tetrad legs, so its
transformation is assembled from three ingredients, each of which we
already have:

1. a **conformal weight** ``κ^w`` — one factor of ``1/κ`` for each
   tetrad leg, plus the weight of the underlying field;
2. a **spin phase** ``e^{i s γ}`` for a component of spin weight ``s``,
   from the ``K`` (Hopf-fiber) rotation by ``γ`` about the null
   direction — this is the ordinary spin-weighted rotation of a field
   on the sphere, and in practice is carried by the rotation/aberration
   of the angular grid rather than applied component-by-component;
3. a **component mixing** generated by the null rotation, with the
   *same* parameter that shears the dyad.

Throughout, ``b`` denotes that null-rotation parameter — the
coefficient of the generator in the transformed dyad.[^b]  From [the
dyad transformation](@ref "BMS action on the tetrad"),

```math
m̃' = \frac{e^{iγ}}{κ}\left(m̃ + b\, ñ\right),
\qquad
b = \frac{ðu'}{2κ}
\quad\text{at } ℐ⁺.
```

[^b]:
    Using [Newman and Penrose's](@cite NewmanPenrose_1966) definition
    of ``ð`` and [the standard tetrad](@ref "The standard tetrad"), we
    can derive the value of this parameter as ``b = ðu'/2κ``.
    [Boyle_2015](@citet) quotes it as ``-ðu'/κ``, but that uses the
    ``ð`` normalization of [GHP_1973](@citet) (whereby
    ``ð_{\mathrm{NP}} = \sqrt{2}\,ð_{\mathrm{GHP}}``) and a different
    tetrad (see the footnote on "[The standard tetrad](@ref)").
    Together, those differences in conventions account for the
    difference in the mixing parameter.

## Weyl components

The Newman–Penrose Weyl components are the contractions
([Conventions](@ref "Metric, curvature, and perturbations"))

```math
\begin{aligned}
ψ_0 &= C_{abcd}\, ℓ^a m^b ℓ^c m^d, &
ψ_1 &= C_{abcd}\, ℓ^a n^b ℓ^c m^d, &
ψ_2 &= C_{abcd}\, ℓ^a m^b \bar m^c n^d, \\
ψ_3 &= C_{abcd}\, ℓ^a n^b \bar m^c n^d, &
ψ_4 &= C_{abcd}\, n^a \bar m^b n^c \bar m^d, &&
\end{aligned}
```

with spin weights ``+2, +1, 0, -1, -2`` and — as we now show — a common
conformal weight ``κ^{-3}``.

### Conformal weight

In spinor form ``ψ_n`` is the Weyl spinor ``ψ_{ABCD}`` contracted with
four basis spinors (the spinor "square roots" of ``ℓ`` and ``n``).
Because *every* tetrad leg carries the uniform Weyl weight ``1/κ`` (the
result ``ĝ' = κ²ĝ`` from [the tetrad page](@ref "BMS action on the
tetrad")), each basis spinor carries ``κ^{-1/2}``, and the four of them
contribute ``κ^{-2}``.  The asymptotic Weyl spinor itself is the
rescaled, finite-at-``ℐ`` field ``ψ = Ψ/ω`` built from the physical
``Ψ``; since ``ω' = κω`` and ``Ψ`` is coordinate-independent, ``ψ``
contributes one further ``κ^{-1}``.  The total is

```math
ψ_n \longmapsto κ^{-3} \times (\text{spin phase}) \times (\text{mixing}),
```

the same ``κ^{-3}`` for all five components.

### Mixing: the peeling tower

The mixing is a null rotation fixing the generator ``ñ`` with parameter
``b``.  Acting on the Weyl tensor through its tetrad legs, this is the
textbook null-rotation tower

```math
ψ_n' = κ^{-3}\sum_{k=0}^{4-n} \binom{4-n}{k}\, b^{\,k}\, ψ_{n+k},
\qquad b = \frac{ðu'}{2κ},
```

up to the spin phase.  Written out,

```math
\begin{aligned}
ψ_4' &= κ^{-3}\, ψ_4, \\
ψ_3' &= κ^{-3}\left(ψ_3 + b\,ψ_4\right), \\
ψ_2' &= κ^{-3}\left(ψ_2 + 2b\,ψ_3 + b^2 ψ_4\right), \\
ψ_1' &= κ^{-3}\left(ψ_1 + 3b\,ψ_2 + 3b^2 ψ_3 + b^3 ψ_4\right), \\
ψ_0' &= κ^{-3}\left(ψ_0 + 4b\,ψ_1 + 6b^2 ψ_2 + 4b^3 ψ_3 + b^4 ψ_4\right).
\end{aligned}
```

Only ``ψ_4`` — the component assembled entirely from the fixed
generator ``ñ`` and the screen — is left unmixed; the tower fills in
the lower components by successive applications of ``b``.  Since ``b``
grows linearly in ``u`` (the lever arm of the [null
rotation](@ref "BMS action on the tetrad")), so does the mixing.

At ``ℐ⁻`` the generator is ``l̃`` instead of ``ñ``, so the null
rotation fixes ``l̃`` and the tower runs the other way — ``ψ_0`` is the
unmixed component and the binomial sum builds ``ψ_4`` from it, now with
the *conjugate* parameter ``\bar b = ð̄v'/2κ`` (see [Past null infinity](@ref fields_scri_minus) below).

## Faraday components

The Maxwell/Faraday components ``φ_0, φ_1, φ_2`` are contractions of
the Faraday spinor ``φ_{AB}`` (rank two) with *two* basis spinors, with
spin weights ``+1, 0, -1``.  The counting is the same as for the Weyl
components but with two legs instead of four: two basis spinors give
``κ^{-1}`` and the rescaled field ``φ = Φ/ω`` gives another ``κ^{-1}``,
for a total conformal weight ``κ^{-2}``.  The null rotation produces the
shorter tower

```math
\begin{aligned}
φ_2' &= κ^{-2}\, φ_2, \\
φ_1' &= κ^{-2}\left(φ_1 + b\,φ_2\right), \\
φ_0' &= κ^{-2}\left(φ_0 + 2b\,φ_1 + b^2 φ_2\right),
\end{aligned}
```

with the same reversal at ``ℐ⁻``.

## Strain, shear, and news

The shear ``σ`` is a different kind of object: it is not a curvature
tensor contracted with the tetrad but a *connection* coefficient, and
it transforms **inhomogeneously** under supertranslations.  This is the
algebraically richest of the transformation laws, and the origin of
gravitational memory.

The asymptotic shear ``σ`` (spin weight ``+2``) measures how a cut of
``ℐ⁺`` fails to be a *good cut*.  Relative to a reference foliation, a
cut at retarded time ``u = f(θ, ϕ)`` carries shear

```math
σ[f] = σ^0 + \tfrac12 ð^2 f,
```

where ``σ^0`` is the shear of the reference cut.  The factor of ``½``
has the same dyad/``\sqrt2`` origin as the ``½`` in the mixing
parameter ``b``: the shear contracts *two* dyad legs into the second
derivative of the cut, ``σ - σ^0 = m̃^A m̃^B D_A D_B f``, and since
``m̃ = (∂_θ + i\cscθ\,∂_ϕ)/\sqrt2`` carries a ``1/\sqrt2`` on each leg,
``m̃^A m̃^B D_A D_B = \tfrac12 ð^2`` in the [Newman–Penrose
normalization](@ref "The eth operator") of ``ð``.  A supertranslation
slides the cut, ``u \mapsto u - εᵅ α``, shifting the shear by
``\tfrac12 ð^2`` of the slide; with the boost weight (the shear carries
``κ^{-1}``) the result at ``ℐ⁺`` is

```math
σ' = κ^{-1}\left(σ + \tfrac12 ð^2 α\right).
```

The inhomogeneous ``ð^2 α`` is the affine action that makes the shear
the Goldstone field of supertranslations: there is no frame in which it
vanishes for all cuts at once, and the difference between its values
before and after a burst of radiation is the memory.

The **strain** ``h`` (spin weight ``-2``) is the conjugate object, and
transforms by the conjugate law,

```math
h' = κ^{-1}\left(h + \tfrac12 ð̄^2 α\right),
```

since ``α`` is real and ``\overline{ð^2 α} = ð̄^2 α``.

The **news** is the retarded-time derivative ``N = ∂_u h`` (spin weight
``-2``).  A ``u``-derivative carries one more factor of ``1/κ`` (because
``u' = κ u``), so the news has conformal weight ``κ^{-2}``.  Crucially,
the supertranslation shift ``ð̄^2 α`` is *independent* of ``u``, so the
derivative annihilates it and the news transforms **homogeneously**:

```math
N' = κ^{-2}\, N.
```

This is the precise sense in which the news is the
supertranslation-invariant (up to weight) part of the radiation, while
the shear is not.

## [Past null infinity](@id fields_scri_minus)

Every ``ℐ⁻`` law follows from the [``ℐ⁻`` tetrad](@ref "BMS action on
the tetrad"), where ``l̃`` and ``ñ`` exchange roles: ``l̃`` is the
generator, ``ñ`` is transverse, and the advanced time ``v`` replaces
``u``.  The null rotation now fixes ``l̃``, shearing the dyad as ``m̃ ↦
m̃ + b\,l̃`` with ``b = ðv'/2κ`` (spin weight ``+1``), exactly as at
``ℐ⁺``.

The Weyl tower, though, is built **not** from ``b`` but from its
conjugate ``\bar b = ð̄v'/2κ`` (spin weight ``-1``) — the one genuine
asymmetry between the two ends.  An ``ñ``-fixed null rotation (``ℐ⁺``)
feeds the parameter ``b`` itself into the tower, but an ``l̃``-fixed
rotation (``ℐ⁻``) feeds ``\bar b``.  Spin weights force it: with the
``l̃``-rich component ``ψ_0`` now unmixed, the tower runs *downward* in
spin from ``ψ_0`` (``s=+2``) to ``ψ_4`` (``s=-2``), and the two terms
in each rung — e.g. ``ψ_1 = ψ_1 + \bar b\,ψ_0`` — share a spin weight
only because ``\bar b`` *lowers* spin:

```math
ψ_n' = κ^{-3}\sum_{k=0}^{n}\binom{n}{k}\, \bar b^{\,k}\, ψ_{n-k},
\qquad \bar b = \frac{ð̄v'}{2κ},
```

so ``ψ_0' = κ^{-3}ψ_0`` and ``ψ_4' = κ^{-3}(ψ_4 + 4\bar b\,ψ_3 +
6\bar b^2 ψ_2 + 4\bar b^3 ψ_1 + \bar b^4 ψ_0)``.  The Faraday tower
reverses the same way (``φ_0`` unmixed, parameter ``\bar b``).  These
reproduce the ``Eᴵ = -1`` branch of `Scri.mix_components!` — which
applies ``conj(ðt′╱2κ)`` — term for term.

The shear and strain keep the ``½`` and flip the sign of the
inhomogeneous term — the ``ℐ⁻`` section is the [antipodal](@ref
scri_pm_conventions) one, which reverses the handedness of ``ð`` —
giving

```math
σ' = κ^{-1}\left(σ - \tfrac12 ð^2 α\right),
\qquad
h' = κ^{-1}\left(h - \tfrac12 ð̄^2 α\right),
```

again matching the code.  The news is unchanged, ``N' = κ^{-2}N``.
